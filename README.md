# Customer-Shopping-Behavior-Analysis
An end-to-end data analytics project using Python, SQL, and Power BI to analyze customer shopping behavior and generate actionable business insights.


## Overview
---
This project analyzes customer shopping data to understand purchasing patterns and customer segments. It covers the full analytics workflow: data loading, exploratory data analysis, data cleaning, SQL analysis, interactive dashboarding, and reporting.

---

## Dataset
 Loading the dataset into Python
- Exploring the dataset structure, columns, and data types
- Identifying missing values, duplicate records, and data quality issues
- Cleaning and pre-processing the data for further analysis
- Loading the cleaned data into PostgreSQL, MySQL, and SQL Server for SQL queries and visualization

## Project Steps

1. **Data Loading** – Loaded the dataset into Python.
2. **Exploratory Data Analysis (EDA)** – Explored data structure, distributions, and patterns.
3. **Data Cleaning and Pre-processing** – Prepared the data for analysis.
4. **SQL Analysis** – Ran analytical queries on PostgreSQL, MySQL, and SQL Server (see `customer_analysis.sql`).

## Results

## Results

The project transforms raw customer shopping data into structured, analysis-ready information and presents findings through Python analysis, SQL queries, and an interactive Power BI dashboard.

The analysis highlights customer purchasing patterns, revenue trends across age groups, and insights that support data-driven business decisions.

## Business Recommendations

- **Focus on high-revenue segments:** Young Adults generated the highest revenue, so target them with tailored promotions and new product launches.
- **Engage every age group:** Revenue is spread fairly evenly across age groups, so use age-specific campaigns to grow the lower-revenue groups, such as Seniors.
- **Reward repeat buyers:** Customers with many previous purchases are valuable, so offer loyalty rewards and exclusive deals to keep them buying.
- **Promote subscriptions:** Use subscription offers and member-only benefits to increase customer retention and repeat purchases.
